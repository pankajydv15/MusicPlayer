# Cloud Beats - Personal Music Player

A minimalist, mobile-first Web App built with **Next.js 14**, **Tailwind CSS**, and the **Web MediaSession API** for background and lock-screen playback.

## Features
- **Background Playback**: Continues playing music even when the screen is locked.
- **Lock-screen Controls**: Artwork, Track Title, Artist, Play/Pause/Skip via native mobile media center.
- **No Manual Uploads**: Search for any official track, unplugged acoustic version, live bootleg, or lofi mashup.
- **Vercel & Netlify Ready**: Serverless API routes built directly into Next.js.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run local development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) on your browser.

## Deployment to Vercel
1. Push this project to GitHub.
2. Go to [Vercel](https://vercel.com) and import the repository.
3. Click **Deploy**.
